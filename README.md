# Prueba Técnica - Data Engineer

Prueba técnica para el cargo de Ingeniería de Datos.

## Ejercicios

### Ejercicio 1
Creación de un dataset confiable de números de teléfono de clientes,
incluyendo validación, control de calidad y prácticas de CI/CD.

### Ejercicio 2
Diseño conceptual de un mecanismo de calidad, trazabilidad,
observabilidad y generación de KPI.

### Ejercicio 3
Procesamiento de saldos históricos de clientes y cálculo de
rachas consecutivas por nivel de deuda.

### Ejercicio 4
Procesamiento de archivos HTML y conversión de imágenes a Base64.

## Tecnologías

- SQL
- Python
- Git
- GitHub
- GitHub Actions

## Estructura

- `ejercicio_1/`: Dataset de teléfonos y CI/CD.
- `ejercicio_2/`: Calidad, trazabilidad y KPI.
- `ejercicio_3/`: Solución SQL de rachas.
- `ejercicio_4/`: Procesador HTML en Python.
